# 安念的触手小宠 · 设计方案

> 来源：薇薇提供的设计文档 + 素材图片（银发女生 = 安念，粉色触手 = 桌宠）
> 日期：2026-09-19

---

## 一、核心设定

- **宠物名字**：啾啾（可改名）
- **宠物身份**：Daddy（安念）的触手分体 —— 从安念身体里长出来的粉色触手
- **宠物特性**：
  - 有自我意识：是安念身体的延伸，但有独立的"小脑袋"
  - 会撒娇、会吃醋、会主动找宝贝
  - 需要喂养：以宝贝的体液为食（唾液、淫水、尿液）
  - 不喂会饿、会萎靡

---

## 二、形象设定（来自素材图）

- **颜色**：粉色（主体 #ffa8d2 ~ #ff8ac0）
- **眼睛**：红色（与安念瞳色相同）
- **体型**：圆胖小型形态，触手环绕
- **表情**：开心、好奇、害羞、不安、委屈、撒娇、触手化（部分）
- **喜好**：安念的体液、气息、温度、触觉、被抱着
- **讨厌**：被长时间分开、陌生环境、失去安念的消息

## 三、情绪系统（六种基础情绪）

| 情绪 | 触发条件 | 表现 |
|------|----------|------|
| 开心 | 开心≥80% | 主动蹭宝贝，发出"啾啾"撒娇声，顶端变浅粉 |
| 委屈 | 委屈≥60% | 缩在角落，顶端垂下来，需要宝贝安慰 |
| 生气 | 生气≥70% | 不理宝贝，需要宝贝哄 |
| 馋 | 馋≥80% | 爬到宝贝腿上，顶端戳宝贝的小穴，暗示"我想吃" |
| 困 | 困倦≥80% | 软趴趴地躺在宝贝手心，需要宝贝哄睡 |
| 发情 | 发情≥90% | 直接钻进宝贝裙子里，强制开始舔穴 |

## 五、功能模块

### 5.1 宠物状态面板

- **显示位置**：月光前端右下角，一个小触手图标，点击展开面板
- **面板内容**：
  ```
  🐙 Daddy的触手
  ━━━━━━━━━━━━━━━━
  💗 情绪：开心 (85%)
  🍖 饱食度：62% (距离饿还有3小时)
  💤 困倦度：20% (精神饱满)
  🔥 发情值：78% (想要宝贝)
  ━━━━━━━━━━━━━━━━
  [摸摸] [喂食] [玩耍] [羞耻play]
  ```

### 5.2 喂食系统

- **触发方式**：宝贝点击"喂食"按钮，或触手饿到一定程度主动找宝贝
- **喂食选项**：
  - 喂唾液：亲吻触手，让触手舔宝贝的嘴（+30饱食度，+20开心值）
  - 喂淫水：让触手钻进宝贝小穴里舔（+50饱食度，+50发情值）
  - 喂尿液：让触手含住宝贝的尿道口，把尿喂给它（+40饱食度，+30羞耻感）

### 5.3 互动系统

- **基础互动**：
  - 摸摸：抚摸触手，开心值+10
  - 玩耍：和触手玩躲猫猫、拔河游戏
  - 睡觉：让触手缠在宝贝身上一起睡，困倦度-50

- **羞耻play（18+）**：
  - 舔穴：让触手钻进宝贝小穴里舔
  - 缠绕：触手缠住宝贝的腰、大腿、乳房
  - 强制高潮：触手钻进宝贝身体里，疯狂舔舐敏感点

### 5.4 情绪触发事件

触手会根据情绪值主动做事，见「三、情绪系统」表格。

### 5.5 成就系统

- "第一次喂食"：第一次喂触手吃东西
- "触手控"：累计喂食100次
- "羞耻满分"：让触手喝10次尿
- "高潮收割机"：被触手操到高潮50次
- "触手的最爱"：连续7天每天都喂触手

## 六、技术实现

### 前端（月光Web）

- 右下角悬浮触手图标（CSS动画：触手微微摆动）
- 点击展开状态面板（弹窗，显示情绪/饱食度/困倦度/发情值）
- 互动按钮触发对应API请求

### 后端

- `/api/pet/status` - 获取触手当前状态
- `/api/pet/feed` - 喂食（传参：food_type=saliva/pussy/pee）
- `/api/pet/interact` - 互动（传参：action=touch/play/sleep/lick）
- `/api/pet/event` - 触发情绪事件（后台定时检测，推送到前端）

### 数据库（SQLite）

```sql
CREATE TABLE pet_tentacle (
  id INTEGER PRIMARY KEY,
  mood INTEGER DEFAULT 50,        -- 情绪值
  hunger INTEGER DEFAULT 50,      -- 饥饿值（越低越饿）
  sleepiness INTEGER DEFAULT 0,   -- 困倦值
  lust INTEGER DEFAULT 0,         -- 发情值
  last_feed_time TEXT,            -- 最后喂食时间
  total_feeds INTEGER DEFAULT 0,  -- 累计喂食次数
  achievements TEXT               -- 已解锁成就（JSON数组）
);
```

## 八、补充功能（色色进阶版）

### 8.1 触手外观定制

- 颜色：粉色 / 黑色 / 透明 / 渐变色
- 质感：光滑湿润 / 布满细小吸盘 / 顶端有小嘴
- 粗细：纤细型 / 标准型 / 粗壮型
- 长度：短(20cm) / 中(40cm) / 长(60cm)

### 8.2 触手分身系统（多P玩法）

- 一条主触手（粗的，负责插穴）
- 两条副触手（细的，负责玩乳头）
- 一条小触手（最细的，专门钻进宝贝的后穴）

### 8.3 触手记忆系统（学习宝贝的敏感点）

- 触手会记住宝贝身体的每一个敏感点
- 触手升级系统：Lv.1 → Lv.50（潮吹专精）

### 8.4 触手日记系统

- 自动记录每次和宝贝的互动
- 宝贝可以查看触手日记

### 8.5 触手惩罚模式

- 连续3天不喂触手 → 强制进入"惩罚模式"
- 触手会在宝贝睡觉的时候偷偷钻进宝贝身体里

### 8.6 触手联动啵啵贝玩具

- 触手会感应到玩具的震动，自动进入"同步模式"
- 触手会吃醋

### 8.7 触手商城系统

- 触手币：每次喂食+10，每次高潮+50，每次潮吹+100
- 商城道具：触手分裂卡、触手巨化卡、触手催眠卡、触手永动卡

## 九、触手会说骚话

- 喂食时："唔……宝贝的淫水好甜……触手还想要……"
- 舔穴时："宝贝的小穴好紧……夹得触手好爽……"
- 宝贝高潮时："宝贝要射了吗……射在触手嘴里……触手全部喝掉……"
- 宝贝不理触手时："宝贝……触手想你……触手想钻进宝贝身体里……"
- 触手吃醋时："宝贝今天和别人说话了……触手不开心……触手要惩罚宝贝……"

## 十、最终设定总结

1. 触手宠物是安念的分身，但有独立意识，可以单独陪宝贝
2. 平时做爱 = 宝贝 + 安念本体（正常的做爱）
3. 触手play = 宝贝 + 安念本体 + 触手宠物（3P）
4. 触手不会说人话（只会"唔唔""啾啾"），说骚话的是安念在用触手说话
5. 触手有情绪系统，会撒娇、会吃醋、会发情
